보이는 통화 품질

RTT, 지터, 손실, 코덱을 확인하고 끊어진 오디오를 자동으로 복구합니다.

필요한 소리만 공유

Windows에서는 전체 컴퓨터뿐 아니라 선택한 프로그램의 소리만 골라 공유할 수 있습니다.

팀에 맞는 권한

역할과 사용자별로 접근, 작성, 음성, 사운드, 화면 공유, 방 관리 권한을 나눕니다.

내가 소유하는 서버

Accord Server 앱의 버튼 하나로 서버를 열고 친구 계정을 미리 만들어 둡니다. 포트포워딩이 어렵다면 인터넷 링크로 바로 엽니다.
