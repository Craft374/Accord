접속 주소

Accord 앱의 서버 주소 칸에 입력하면 들어올 수 있습니다. 밖에 있는 친구가 들어오려면 공유기에서 이 포트를 열어(포트포워딩) 공인 IP 주소로 접속해야 합니다.

창을 닫아도 서버는 계속 켜져 있습니다.

미리 만든 계정

여기서 만든 계정만 보입니다. 다른 사람이 직접 가입한 계정이나 접속 기록은 보이지 않습니다.

바뀐 설정은 서버를 다시 켜야 적용됩니다.
